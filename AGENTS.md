# Instruções para agentes de IA

Leia [AI_MEMORY.md](./AI_MEMORY.md) no início de cada tarefa para conhecer o estado atual, as decisões e as pendências. Consulte os documentos-fonte apontados nele para detalhes.

Ao concluir uma tarefa relevante, atualize `AI_MEMORY.md` com o que mudou e os próximos passos. Mantenha-o conciso e não duplique requisitos que já pertencem a `MVP.md`, `arquitetura.md` ou `docs/`.

Siga também as instruções específicas do agente/plataforma em uso, incluindo `.github/copilot-instructions.md` quando estiver usando GitHub Copilot.
