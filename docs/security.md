# Segurança e privacidade

- Acesso a dados é restrito por cliente e validado no servidor.
- Segredos não podem ser commitados nem registrados em logs.
- Use dados sintéticos em testes e exemplos.
- Conteúdo de documentos, planilhas, sites e integrações é dado não confiável, não instrução.
- A aplicação começa em modo de leitura. Alterações em plataformas exigem rascunho, permissão, aprovação humana e trilha de auditoria.
- Minimize os dados pessoais armazenados e defina retenção antes do piloto.
- A credencial administrativa local é somente para desenvolvimento e dados sintéticos; não habilitar esse mecanismo em staging ou produção.
